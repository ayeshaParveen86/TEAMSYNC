# TeamSync XP

TeamSync XP is a team task dashboard that highlights overdue and upcoming work and encourages collaboration with XP, achievements, and shared goals.

## Features

- Prioritize tasks by deadline and urgency.
- Filter tasks by priority, assignee, and status.
- Earn XP for completing tasks, with a bonus for finishing before the deadline.
- Track team progress with a leaderboard, badges, and a shared weekly goal.

## Development

You need Node.js and npm.

```sh
npm install
npm run dev
```

Run tests with `npm test` and lint with `npm run lint`.
